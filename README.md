# NeuroScan — AI-ассистент врача-рентгенолога

Проект создан для участия в кейсе «ИТ-стартап». 
Тема: «AI-Радиолог: Второе мнение для региональной медицины».

##  Что это?
Лендинговая страница для продвижения медицинской нейросети «NeuroScan», которая помогает врачам-рентгенологам быстрее анализировать снимки КТ и рентгена.

На сайте реализовано:
1. Полный дизайн по заданию (герой-секция, боли, безопасность, экономика, кейс).
2. Интерактивный слайдер «До/После».
3. **Живое AI-демо** (собственная модель, обученная в Teachable Machine).

## Как работает нейросеть?
В основе лежит модель, обученная в Google Teachable Machine (TensorFlow.js). Она загружается прямо в браузере пользователя и анализирует загруженный снимок, выдавая вероятность наличия пневмонии. 

## Структура проекта
* `index.html` — разметка сайта.
* `styles.css` — все стили и адаптивность.
* `app.js` — логика слайдера, формы и нейросети.
* `model/` — файлы обученной модели (`model.json`, `metadata.json`, `weights.bin`).
